# VET67-206 — Journal Presentation Study Guide

An interactive, single-page study site for the Week-15 journal presentation in **General Biochemistry (VET67-206)**. It helps students learn each of the seven assigned papers.

## What's inside

For each paper (Case A–G, with its randomly assigned group number):

- **Overview** — the message to deliver, a plain-language method primer, and what to set aside.
- **Figure walkthrough** — the "present these figures, in this order" path as numbered steps.
- **Flashcards** — key biochemistry concepts, tap to flip.
- **Self-quiz** — multiple-choice questions with instant feedback and explanations.

Plus a searchable **glossary** of every enzyme, pathway, and term across all seven papers.

## Use it

The whole site is a single self-contained `index.html` — no build step, no dependencies. Open it directly in a browser, or host it free with **GitHub Pages** (Settings → Pages → deploy from the `main` branch).
